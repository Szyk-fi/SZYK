What’s inside

One box. A whole studio.

ROVE is built around a single idea: every app shares the same engine, the same controls and the same patch bus, so everything works with everything.

01

Instruments, effects, sequencers

Synths, drum machines, loopers, granular clouds, tape and reverb, step sequencers and generative ones. Over a hundred apps in one launcher.

02

Controls you learn once

A 4×4 pad grid, a D-pad, two encoders and F1–F4. Every app uses them the same way, and every app draws its own 640×360 screen.

03

Everything patches to everything

Pick another app’s output as your input. Route a modulation source to any parameter. Map MIDI CCs by touch. No cables, no menus-within-menus.

04

The real DSP, not look-alikes

Several apps run the actual open-source Mutable Instruments engines (Plaits, Clouds, Warps, Beads) as compiled C++, not approximations of them.

05

AI that runs on the chip

Seven apps are built around small neural networks sized for the STM32N6’s NPU. One of them tracks the pitch of your voice a hundred times a second.

06

I/O on swappable cards

Two M.2 card slots carry line in/out and MIDI DIN today, and only digital signals cross the connector. Different cards, different jacks.

How we build it

No fakes.

If an app says it’s a filter, it’s that filter. If it says it’s a sequencer clock division, it divides the clock. We would rather say “not done yet” than ship something that only looks right.

Mutable Instruments published its firmware as open source, and ROVE runs it directly. Thank you, Émilie Gillet.

  • 1
    Real-time, alwaysThe audio thread never blocks, allocates or waits. A missed deadline is a glitch you can hear, so it’s treated like a bug.
  • 2
    Tested against behaviour“Hold a pad and it makes sound, let go and it goes quiet” is a test. “It constructs without crashing” is not.
  • 3
    Honest limitsEvery hardware claim that hasn’t been proven on silicon is labelled that way in the code and the manual.

Questions

Good questions.

Is ROVE a real device yet?

ROVE is the hardware we’re crowdfunding. The apps already run today in a full desktop simulator, built so the architecture could be proven before any hardware exists. The device itself is designed around an STM32N6 processor.

Is the demo above the real engine?

No. It’s a browser preview: five small Web Audio voices written for this page, wired to a replica of the control surface. They show how ROVE feels to play, not how it sounds. The real apps run on the native engine, including the Mutable Instruments DSP.

What controls does it have?

A 4×4 pad grid, a D-pad, two encoders and four function buttons (F1–F4), with a 640×360 screen. In the simulator you can also drive it from a MIDI controller or a game controller.

How do I get audio in and out?

Through I/O cards. ROVE has two M.2 card slots; in the current design one holds a stereo line in/out card and the other a MIDI DIN card. Only digital signals cross the connector, so new cards can add different jacks later.
