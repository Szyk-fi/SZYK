# Chip music

Drop chip-music files here (and in one level of subfolders) and the **Chip
Player** app lists them: `.nsf` `.nsfe` (NES), `.spc` (SNES), `.gbs` (Game
Boy), `.vgm` `.vgz` `.gym` (Mega Drive / Master System / arcade chips), `.hes`
(PC Engine), `.kss` (MSX), `.ay` (ZX Spectrum), `.sap` (Atari).

Nothing here is committed: the files are other people's music, and each
collection has its own licence. Game soundtracks ripped from cartridges belong
to their publishers, so these stay on your machine, like ROMs and samples.
